# 内部引用

生图工具的 `references` 已支持这些写法。批量工具 `batch_tasks` 还没有接入。

## 语法

每一项去掉首尾空白后识别，区分大小写。最多 16 项，单项不超过 512 字符。重复项只保留第一次。

| 写法 | 含义 |
| --- | --- |
| `current` | 当前消息和被引用消息里的图 |
| `avatar:sender` | 发送者头像 |
| `avatar:mentioned` | 当前消息里手动 @ 的用户头像，不含机器人和自动 @ |
| `avatar:<用户ID>` | 指定用户头像，只接受发送者或当前消息 @ 到的人 |
| `gen:last` | 本会话最近一次成功生成的第 1 张 |
| `gen:<记录ID>`、`gen:<记录ID>#<序号>` | 指定记录的第 1 张或第 n 张，序号从 1 到 20 |
| 绝对路径、`file://`、Windows 盘符路径 | 本地文件，沿用工具路径白名单 |

相对路径、`~`、带 `..` 的路径、未知前缀、裸 `avatar:`、裸 `gen:`、以及 `#0`、负数、非数字序号都会拒绝。

## 生成记录

记录保存会话标识。没有该字段的旧记录不能被 `gen:` 引用；当前会话标识为空时也不能引用。`succeeded` 和 `partial_success` 且有图的记录可以引用、可以共享。`gen:last` 不带序号，任务号也不能使用 `last`。其他会话的记录只有已经共享，或打开 `reference_cross_session`，才能引用；否则只返回“无权引用”，不说明记录是否存在。

历史记录关闭、图片已清理或正在清理时，返回“参考图片不存在或正在清理，请重新选择”。

共享标记默认关闭。只有记录上的请求者本人可以修改。WebUI 和公开 SDK 的返回结果不包含会话标识，可以包含共享状态。

用户提交的本地路径和插件画廊文件分开保存。画廊文件在作用域检查通过后按受信文件使用，用户路径仍要先过白名单。
