# 使用指南

## 生图供应商选择

v2.0.0 起，插件只使用 `供应商配置` 中配置的生图供应商。

- `provider_polling` 留空时，插件会按有效供应商配置自动尝试。
- `provider_polling` 填写后，插件按列表从上到下尝试；重复供应商自动去重，未知供应商会记录错误并跳过。
- 同类型多条供应商配置按 `priority` 从高到低尝试；相同优先级按配置表顺序尝试。
- 带参考图的 `/改图`、`/换风格`、头像参考等请求会自动跳过不支持改图的供应商。

命令提示词首个参数可指定生成路由，适用于 `/生图`、`/改图`、`/换风格` 和各快速模式：

| 写法 | 行为 | 示例 |
|------|------|------|
| 不指定 | 按原有顺序轮询全部有效候选 | `/生图 雨夜城市` |
| `供应商/模型` | 只在指定供应商和模型的候选内重试 | `/生图 xai/grok-imagine-image-2.0 雨夜城市` |
| `供应商/` | 只在该供应商的已配置模型内重试 | `/生图 xai/ 雨夜城市` |
| `模型或别名` | 匹配多个供应商时仍按原有顺序轮询 | `/生图 fast-image 雨夜城市` |

模型别名在每条供应商配置的 `model_alias` 中设置。查询和统计会同时保留原始模型名；实际上游请求始终发送原始模型名。

## 智能头像功能

启用 `auto_avatar_reference` 后，插件会根据自然语言自动获取头像作为参考图：

| 触发方式 | 行为 |
|----------|------|
| `按照我` / `根据我` / `基于我` / `我的头像` | 获取发言人头像 |
| `@某人` + 生图/改图命令 | 获取被 @ 用户头像 |

优先级：`@ 指定用户 > 发言者自己`。

## 快速模式

| 模式 | 默认分辨率 | 默认比例 | 说明 |
|------|------------|----------|------|
| 头像 | `1K` | `1:1` | 个人头像 |
| 海报 | `2K` | `16:9` | 宣传海报 |
| 壁纸 | `4K` | `16:9` | 高清壁纸 |
| 卡片 | `1K` | `3:2` | 名片卡片 |
| 手机 | `2K` | `9:16` | 手机壁纸 |
| 手办化 | `2K` | `3:2` | 树脂手办效果，参数 `1` 为 PVC，`2` 为 GK |
| 表情包 | `4K` | `16:9` | Q 版 LINE 风格表情包 |

快速模式的默认分辨率和比例可通过 `quick_mode_settings` 覆盖。

## 切图指令

- 智能切分：`/切图`
- 手动网格：`/切图 4 4`、`/切图 44`、`/切图4x4`
- 主体吸附：指令包含 `吸附` 时启用主体+附件吸附算法

切图流程：

```text
手动网格 > AI 识别（需配置 vision_provider_id）> 智能网格 > 主体吸附兜底
```

表情包生成质量和模型输出强相关。如果模型没有生成稳定网格，自动切图可能切到主体、文字或空白区域。遇到这类情况优先尝试手动网格，或使用专门切图工具二次处理。

## LLM 工具集成

插件注册以下三个工具：

- `gemini_image_generation`：单次或批量生图。
- `gemini_image_provider_models`：查询供应商、原始模型、别名、生成模式；设置 `detail=true` 时返回该模型在生图工具中实际支持的参数。
- `gemini_image_task_status`：按任务号查询当前会话的后台进度和结果摘要。

模型可以用自然语言触发生图：

- `帮我画一只可爱的小猫`
- `把我的头像改成动漫风格`
- `基于这张图生成一个海报`

### 前台/后台混合模式

LLM 工具会根据当前 `tool_call_timeout` 和 `llm_tool_timeout_reserve_percent` 计算前台等待窗口：

- 图片在窗口内生成完成时，以 `CallToolResult` 结构化返回图片。
- 超过等待窗口时，自动切到后台继续生成，完成后通过 `event.send()` 直接发送给用户。
- 转入后台时返回 JSON，其中包含 `task_id`、`status`、`routing_mode` 和当前轮询/重试说明。

代理模式下，前台和后台都会通过代理下载远程图片，保证链路一致。

### 工具参数

LLM 工具支持可选 `provider` / `model` 路由参数。二者都不传时完整轮询；只传供应商时仅在该供应商内重试；只传模型或别名时跨供应商保持原轮询顺序；两者都传时只使用交集候选。

工具还暴露以下可选生成参数：

- `resolution`：仅支持 `1K` / `2K` / `4K`。
- `aspect_ratio`：仅支持 `1:1` / `16:9` / `4:3` / `3:2` / `9:16` / `4:5` / `5:4` / `21:9` / `3:4` / `2:3`。
- 未传入时使用插件配置或供应商默认值。
- `negative_prompt` / `watermark` / `quality`：只允许支持对应参数的候选参与生成；可通过模型查询工具的详细模式获取合法参数和枚举。
- `preserve_reference_image_size`：有参考图时保留其尺寸；省略时读取插件配置。启用后不能同时显式传入尺寸、分辨率或比例。

### 批量生成

`gemini_image_generation` 的 `batch_tasks` 会直接进入后台。每个条目必须包含唯一 `name`、完整 `prompt`、`image_count`，并至少指定 `provider` 或 `model`。插件按配置并发执行；供应商支持原生批量时优先按其单次上限提交，不支持时逐张生成，返回数量不足时会继续补齐。

### 参数校验

LLM 传入非法 `resolution` 或 `aspect_ratio` 时，工具会记录警告并回退为默认配置。

### Gemini thought_signature 处理

插件会把 Gemini 返回的 `thought_signature` 视为仅限协议层使用的 opaque 元数据，不会拼进 Tool 文本结果或用户可见内容。这可以避免部分 Gemini / NewAPI 网关把超大签名重新塞回上下文，导致 `413` 或输入 token 超限。

## WebUI 创作台

插件在 AstrBot Dashboard 提供「studio」插件页（需宿主提供 `astrbot.api.web` 接口；缺少该接口的旧版本自动跳过注册，其余功能不受影响），入口：插件管理 → 本插件 → 页面，或侧边栏插件页入口。

### 工作台

- 模型下拉按「供应商 · 模型」扁平直选（按供应商分组、显示别名），选中后分辨率/比例等可选项随该供应商能力联动。
- 基础区设置模型、分辨率、画面比例和总张数；点击「供应商生成参数」打开独立弹窗，表单内部滚动，底部固定「取消」「保存并应用」。勾选才覆盖，取消、Esc、关闭或切换模型均丢弃未确认修改，不再撑长工作台侧栏。Key、接口地址、代理和供应商管理项不开放。
- 临时参数点击「保存并应用」后才用于后续工作台任务并按浏览器、候选记忆；弹窗内「恢复默认参数」也需保存才生效，仅清除弹窗参数覆盖，不重置外部分辨率、比例与张数。普通页面使用浏览器本地存储；AstrBot 沙箱通过 bridge 保存到插件数据目录 `webui_preferences/`，记忆失败不影响当前已应用的参数，会显示状态提示。
- 总张数仍由上方控制。临时覆盖 `n` 时，它限制每次供应商请求的张数，工作台会继续补足总目标。批量任务共享本次临时参数，每个子项保留自己的提示词和张数。
- 支持单任务多张（自动补足目标张数）与批量模式（多个命名子任务并发执行）。
- 参考图可本地上传或从历史画廊拾取；工作台生成占用共享全局限流额度，不占聊天 UMO 的会话额度，结果只进 WebUI、不发送到会话。
- 上传暂存文件在任务受理后受租约保护，等待执行或生成中的单任务及批量子任务不会因 24 小时过期清理或容量淘汰丢失参考图；共享文件在所有持有任务退出后恢复正常清理。启动失败、取消和服务关闭均释放租约，容量不足时拒绝新上传（507）。

### 任务进度

指令、LLM 工具、LLM 批量、工作台所有来源的生成任务实时展示（状态/耗时/供应商模型/结果缩略图），批量任务父子聚合。任务卡片、历史画廊和大图预览同时展示群聊/私聊类型、群号及发起用户的昵称和 ID；工作台直接发起的任务标为「工作台提交」。旧记录有群号时显示群聊，缺少会话类型和群号时显示「会话类型未知」，无法补回原本未记录的信息。供应商、模型和别名优先展示实际成功的结果，运行中尚无成功统计时使用请求参数。任务创建即落盘：刷新页面可继续查看，插件重启后未完成任务标记为已中断。

### 历史画廊

每次生成自动归档到独立 gallery 目录并记录元数据（提示词/来源/群/用户/耗时/供应商/模型），支持分页与筛选、灯箱查看、下载、删除（单个/批量）、复制提示词、再次生成回填、用作参考图。升级后首次启动自动把存量生成图迁入画廊。画廊容量由 `webui.gallery_max_size_mb` 控制，超限整组清理图片但保留记录。

失败的生成记录只在任务进度中展示，画廊筛选与分页不包含失败记录。

使用画廊图片图生图时，会记录「参考图 → 当前结果」的关系。画廊和任务卡片可直接把来源图片设为参考图；「再次生成」会回填仍可用的参数和原参考图，替换工作台之前的输入，已清理或超出当前模型上限的参考图会提示并跳过。运行中任务使用的参考图暂时受到保护，任务结束后恢复正常删除和配额清理。

超出原图显示限制的图片自动提供压缩预览，并提示「原图超过显示限制，请下载查看」；大图窗口内可下载原图，归档文件不会被压缩预览覆盖。

### 限流控制

- 顶部「群限制与黑白名单」支持不限制、白名单、黑名单，群号每行一个，模式切换不清空名单；与下方限流规则一起保存并即时生效。名单只限制群聊；空白名单保持原行为（不限制群），界面会明确提示。
- 设置「全局限流」与「默认会话限流」，两者叠加；前者所有来源共享，后者每个 UMO 独立计数。单任务计 1 次，批量按子任务数计数，不按出图张数计数。
- 添加指定会话规则，点击「选择会话 / 手动粘贴 UMO」按名称、UMO、类型或平台搜索，勾选即填入草稿；翻页不丢失选择，也可每行粘贴一个完整 UMO。规则按顺序取第一个启用匹配，空 UMO 表示所有会话分别计数。
- 会话来自本体已记录的对话与会话名称，不是实时好友/群通讯录；短缓存最多 10 秒。旧宿主缺少名称接口时显示 UMO，枚举失败仍可手填。选择仅用于配置，不会以该会话身份发起 Studio 生图。
- 修改后点击「保存限流配置」，即时生效且不重载插件、不清空计数。加载失败禁用保存，保存失败保留草稿；遇到版本冲突先核对草稿，再确认重新加载服务器配置。
- 旧群号规则需选择完整 UMO、明确「确认迁移」后保存；未迁移的启用规则会暂停聊天生图，历史计数也可能触发短期迁移保护。备份及回退说明见 [限流配置](config.md#limit_settings)。

### 供应商配置

- 二级 Tab 分为「配置条目」「轮询排序」「公共设置」，切换保留草稿，不把长表单平铺在页面上。配置表独立滚动，点击编辑打开分组弹窗，高级字段默认折叠。
- 弹窗「应用到草稿」只确认本条编辑；最后点击页面「保存供应商配置」才持久化。取消或关闭弹窗不应用本次编辑；新增条目默认停用。
- 在轮询页拖动手柄排序，也可用上移／下移按钮或手柄方向键；手机支持触摸拖动。首次拖动自动预览会切换为手动轮询，「恢复自动轮询」还原空列表；移出轮询不会删除配置条目。
- 状态列可直接启停条目，先更新草稿再统一保存。Key 默认以「••••••••」省略显示（同本体密钥控件），点击「显示」后才明文；单个 Key 明文为单行输入，多个 Key 显示标签摘要和数量。点击「管理 Key」在当前弹窗内逐项添加、编辑或移除，批量导入时才显示多行输入。
- 密钥管理的「完成」只更新条目编辑草稿；取消恢复原列表且保留其他字段。Enter 添加／确认行编辑，Esc 逐层取消行编辑、批量导入和密钥管理；未确认的行编辑或待添加输入会阻止完成。
- 接入端点等连接选项放在通用区，豆包可直接切换 `official` / `agent_plan`，不自动改动基础地址或清空 Key。
- 视觉提供商是本体现有 LLM 配置的下拉，支持刷新名单及手填回退；不是本插件的生图供应商列表，也不只列举已经加载的实例。
- 模型旁点击「拉取模型」后搜索、点选，选中只填写草稿；原值和自由输入始终保留。连接参数变化或关闭弹窗后丢弃迟到结果；新目标使用已有 Key 时会在当前弹窗内要求确认。目录接入范围见 [模型目录](config.md#模型目录与视觉提供商)。
- 有生成任务时保存会被拒绝，草稿保留，任务结束后可重试；空闲时热更新并刷新工作台模型能力，不取消任务、不重置额度。版本冲突先核对草稿再重新加载；异常恢复需重载时会明确提示。详见 [配置保存](config.md#studio-配置保存)。

### 隐私与配额配置

`webui` 配置段：`history_enabled`（关闭后不写历史记录）、`history_max_records`、`gallery_max_size_mb`、`upload_max_mb`、`max_concurrent_jobs`（工作台全局并发）、`batch_total_budget`（单次批量图片总预算）。

## 论坛发帖模式

当用户明确要求将图片发到论坛或 AstrBook 时，LLM 会设置 `for_forum=true`。此时工具会同步等待生成完成并返回图片路径或 URL，LLM 可继续调用 `upload_image` 上传图床后自动发帖。

## 表情包切分算法

SmartMemeSplitter v4 包含：

- 颜色边缘突变分析：彩色形态学梯度 + OTSU 自适应阈值
- 能量图分析：基于 Sobel 算子的多通道能量计算
- 投影分析：水平/垂直投影检测网格边界
- 网格候选微调：精细调整以寻找更清晰的分隔线

主体吸附算法会尝试去除白底、提取前景掩码、识别主体与附件，并把裁剪结果转为透明背景。该路径适合作为兜底，不保证能处理所有模型输出。
