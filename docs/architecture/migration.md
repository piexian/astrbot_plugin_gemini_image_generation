# v2 调度器迁移与回滚指南

## 适用范围

v2 已覆盖命令、LLM 工具单图/批量、WebUI 创作台和公开 SDK。`scheduler_v2` 默认关闭，旧路径仍是默认执行路径；迁移不改变现有供应商配置格式，只新增调度开关和灰度名单。

## 推荐开启步骤

1. 保存当前插件配置，并确认生成历史、后台任务和供应商配置可用。
2. 在目标会话执行 AstrBot `/sid`，取得完整 `unified_msg_origin`（UMO），不要自行拼接群号或平台名。
3. 将该 UMO 加入 `image_generation_settings.scheduler_v2_sessions`，再开启 `image_generation_settings.scheduler_v2`。
4. 先验证该会话的命令、LLM 工具单图和批量，再验证带同一 `umo` 的 SDK 调用；检查任务状态、图片投递和生成历史。
5. 扩大到其他会话。确认全量接入后清空灰度名单，使所有已接入入口随总开关运行。

WebUI 没有会话 UMO，公开 SDK 也允许不传 `umo`：只有灰度名单为空时，这两类调用才随总开关进入 v2；名单非空时保持旧路径。

## 行为差异

- **统一准入**：额度与生成队列在提交时预留，拒绝发生在任务创建前；已接受任务之后失败或取消不退额度。命令的拒绝提示先于“生成中”等进度提示。
- **错误与完成口径**：v2 用户提示沿用旧路径措辞；生成核心收到无图结果按失败处理，命令快捷路径仍允许纯文本成功。已成功写入的历史不会被后续投递失败改写。
- **LLM 工具**：取消前台调用会同时取消生成；前台结果构建超时直接返回图片 URL/本地路径文本，不再转后台。批量使用父子 Job，子任务独立 deadline 并自动补足张数，最终统一回灌汇总；投递失败保留结果为 `partial`。
- **WebUI**：单图/批量参考图先入库再释放上传租约；生成队列满或服务关闭在提交时返回 429/503，而不是受理后在任务中失败。历史按归档结果判定成功、部分成功或失败。
- **公开 SDK**：任务记录、等待、取消和回调保持兼容；HTTP(S) 参考图受 SSRF 策略限制，本地文件先转临时句柄，队列满稳定抛出 `code="queue_full"`。
- **历史源链接**：`source_urls` 的 query、fragment 和 userinfo 会被移除，旧记录仅在 API 响应中脱敏。失败任务不能再凭带签名参数的源链接手动取回图片，成功任务的 gallery 图片不受影响。
- **供应商与出站安全**：已保存 API Key 只显示数量与掩码；未保存到供应商配置的内网地址默认拒绝，需先保存对应 `api_base`。模型目录与归档下载拒绝 link-local/元数据地址，归档重定向逐跳复检。
- **WebUI 授权**：供应商配置、历史删除、限流、会话、上传等管理操作仅允许面板用户；API Key 可继续使用任务提交与历史读取接口。

## 配置与数据兼容

没有配置格式迁移，只有 `scheduler_v2` 与 `scheduler_v2_sessions` 新键；关闭开关不会修改供应商、限流或历史配置。

- v2 任务库位于插件数据目录的 `v2/`，主要文件为 `jobs.sqlite3`，使用 SQLite WAL。
- 生成历史继续使用旧格式与 `partial_success` 等兼容状态；v2 Job ID 比旧记录更长，调用方应将其视为不透明字符串。
- 临时参考图句柄是进程内资源，崩溃后不保证可恢复；恢复出的无运行属主任务按 interrupted/orphaned 处理，不自动重放。
- 旧 `background_tasks.json` 和 `generation_history.json` 的兼容导入与损坏恢复逻辑保留。

## 回滚

1. 关闭 `scheduler_v2`。之后提交的新请求回到旧路径；需要按会话回滚时，也可把目标 UMO 从灰度名单移除。
2. 插件关闭或重载时，进行中的 v2 任务会被取消并标记 interrupted，不会自动迁移成旧后台任务；已完成的生成历史和图片保留。
3. v2 任务库可以保留以便诊断。确认不再需要后，先停止插件，再删除插件数据目录下的 `v2/`；不要在调度器运行时删除数据库。
4. 如需恢复旧任务库，从备份恢复整个 `v2/` 目录；回滚本身不要求执行数据降级脚本。

## 旧逻辑弃用与删除

旧路径函数仅以文档字符串标记弃用，不发出运行时警告。删除重复逻辑需同时满足：四个入口在 v2 下稳定运行一段时间、回滚路径与兼容测试充分、默认开关已切换为开启。之后按“先弃用、再默认切换、最后删除”的顺序执行，并单独发布行为说明。
